# 部署文档

## 1. 环境准备

### 1.1 硬件要求

| 项目 | 最低配置 | 推荐配置 |
|------|---------|---------|
| CPU | LoongArch 4核 | 8核及以上 |
| 内存 | 4GB | 8GB及以上 |
| 磁盘 | 20GB | 50GB及以上 |
| 网络 | 内网可达 | 可访问 LLM API |

### 1.2 软件环境

- **操作系统**: 麒麟高级服务器版 V11 (kylin v10sp3 兼容)
- **Python**: 3.9 或更高版本
- **pip**: 21.0 或更高版本

### 1.3 前置检查

```bash
# 检查 Python 版本
python3 --version

# 检查系统架构
uname -m

# 检查操作系统版本
cat /etc/os-release

# 安装基础依赖（如有需要）
sudo yum install -y python3 python3-pip python3-venv
```

## 2. 部署步骤

### 2.1 获取代码

```bash
git clone <repository-url>
cd kylin-ops-agent
```

### 2.2 配置大模型

编辑 `config/agent.yaml`：

```yaml
llm:
  provider: "openai_compatible"
  api_base: "https://api.deepseek.com/v1"  # 或其他兼容 API
  api_key: "sk-your-api-key-here"
  model: "deepseek-chat"
  temperature: 0.3
  max_tokens: 4096
```

如果使用本地模型（如 vLLM / Ollama）：

```yaml
llm:
  provider: "openai_compatible"
  api_base: "http://localhost:8000/v1"
  api_key: "sk-dummy"
  model: "qwen3-8b"
```

### 2.3 安装依赖

```bash
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2.4 创建受限用户（推荐）

```bash
# 创建 opsagent 用户用于执行运维命令
sudo useradd -r -s /bin/bash -m opsagent

# 如需允许 sudo（仅用于需要提升权限的操作）
sudo usermod -aG wheel opsagent  # 或添加到 sudoers
```

### 2.5 配置安全规则（可选）

编辑 `config/agent.yaml` 中的 `security` 部分：

```yaml
security:
  restricted_user: "opsagent"
  dangerous_commands:
    - "^\\s*rm\\s+-rf\\s+/"
    - "^\\s*mkfs\\."
  confirm_required_patterns:
    - "rm\\s+.*-rf"
    - "kill\\s+-9"
  allowed_command_prefixes:
    - "ps"
    - "df"
    - "free"
    # ... 更多前缀
```

### 2.6 启动服务

#### 方式一：使用启动脚本（推荐）

```bash
cd backend
chmod +x run.sh
./run.sh
```

#### 方式二：手动启动

```bash
cd backend
source venv/bin/activate
mkdir -p logs/audit
python3 -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

#### 方式三：生产环境（systemd）

创建 `/etc/systemd/system/kylin-ops-agent.service`：

```ini
[Unit]
Description=Kylin Safe Ops Agent
After=network.target

[Service]
Type=simple
User=opsagent
WorkingDirectory=/opt/kylin-ops-agent/backend
Environment="PATH=/opt/kylin-ops-agent/backend/venv/bin"
ExecStart=/opt/kylin-ops-agent/backend/venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

启用并启动：

```bash
sudo systemctl daemon-reload
sudo systemctl enable kylin-ops-agent
sudo systemctl start kylin-ops-agent
sudo systemctl status kylin-ops-agent
```

## 4. 安全配置

### 4.1 防火墙

```bash
# 开放 Agent 服务端口
sudo firewall-cmd --permanent --add-port=8000/tcp
sudo firewall-cmd --reload
```

### 4.2 Nginx 反向代理（推荐生产环境）

```nginx
server {
    listen 80;
    server_name ops-agent.example.com;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

### 4.3 审计日志管理

审计日志默认存储在 `backend/logs/audit/` 目录下：

```bash
# 查看今日审计日志
tail -f backend/logs/audit/audit.log

# 查看链路记录
ls backend/logs/audit/chain_*.jsonl

# 日志轮转（建议配置 logrotate）
```

## 5. 常见问题

### Q1: 启动时报 "ModuleNotFoundError"

确保激活了虚拟环境：

```bash
cd backend
source venv/bin/activate
```

### Q2: LLM 调用失败

检查 `config/agent.yaml` 中的 API 配置，确认网络可达：

```bash
curl <api_base>/models -H "Authorization: Bearer <api_key>"
```

### Q3: 工具执行无输出

检查 opsagent 用户是否有足够权限执行系统命令：

```bash
sudo -u opsagent ps aux
sudo -u opsagent df -h
```

### Q4: 前端页面无法访问

确认前端文件存在于 `frontend/` 目录，且 FastAPI 已正确挂载静态文件。

## 6. 卸载

```bash
# 停止服务
sudo systemctl stop kylin-ops-agent
sudo systemctl disable kylin-ops-agent
sudo rm /etc/systemd/system/kylin-ops-agent.service

# 删除项目目录
sudo rm -rf /opt/kylin-ops-agent

# 删除用户（可选）
sudo userdel -r opsagent
```
