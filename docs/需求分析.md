# 软件功能需求分析文档

## 1. 项目背景

在企业级数据中心（教育、医疗等行业），运维人员常需处理复杂的操作系统问题（僵尸进程堆积、磁盘 I/O 异常、配置文件漂移）。传统运维依赖复杂的脚本和监控告警，门槛极高。本系统通过自然语言交互降低运维门槛，同时引入多层安全机制防止 AI 误操作。

## 2. 功能需求

### 2.1 OS 环境深度感知

| 编号 | 功能 | 描述 | 优先级 |
|------|------|------|--------|
| F1-1 | 系统信息采集 | 自动调用 uname、uptime 等获取内核、架构、运行时间 | 高 |
| F1-2 | 资源监控 | 采集 CPU、内存、磁盘、网络实时指标 | 高 |
| F1-3 | 进程分析 | 获取进程列表、僵尸进程、进程详细信息 | 高 |
| F1-4 | 日志检索 | 支持 journalctl 和文件日志搜索 | 中 |
| F1-5 | I/O 诊断 | 采集 iostat、vmstat 等磁盘 I/O 数据 | 中 |

### 2.2 MCP 运维插件化

| 编号 | 功能 | 描述 | 优先级 |
|------|------|------|--------|
| F2-1 | 工具注册 | 支持动态注册和发现运维工具 | 高 |
| F2-2 | 标准化接口 | 遵循 MCP 协议规范的工具调用格式 | 高 |
| F2-3 | 错误处理 | 工具执行异常的安全降级 | 高 |
| F2-4 | 执行超时 | 支持命令超时控制 | 中 |

### 2.3 安全意图校验器

| 编号 | 功能 | 描述 | 优先级 |
|------|------|------|--------|
| F3-1 | 提示词注入检测 | 识别 ignore previous instructions 等注入模式 | 高 |
| F3-2 | 恶意意图识别 | 检测删除系统文件、格式化磁盘等恶意诉求 | 高 |
| F3-3 | 命令风险分级 | 基于规则引擎对命令进行 safe/low/medium/high/critical 分级 | 高 |
| F3-4 | 白名单校验 | 只允许执行预定义的安全命令前缀 | 中 |
| F3-5 | 二次确认机制 | 中危及以上操作需要管理员确认 | 高 |

### 2.4 最小权限代理执行

| 编号 | 功能 | 描述 | 优先级 |
|------|------|------|--------|
| F4-1 | 用户隔离 | 核心操作在 opsagent 受限用户下执行 | 高 |
| F4-2 | 只读模式 | 信息收集类命令使用最严格的只读权限 | 高 |
| F4-3 | 环境隔离 | 限制 PATH、HOME 等环境变量 | 中 |
| F4-4 | 超时控制 | 防止命令长时间挂起 | 中 |

### 2.5 推理链路溯源

| 编号 | 功能 | 描述 | 优先级 |
|------|------|------|--------|
| F5-1 | 链路记录 | 记录完整闭环：接收指令→感知环境→推理决策→安全校验→执行结果 | 高 |
| F5-2 | 节点追踪 | 每个处理阶段记录输入输出、耗时、状态 | 高 |
| F5-3 | 审计查询 | 支持按时间、状态、会话查询历史链路 | 中 |
| F5-4 | 日志持久化 | JSONL 格式存储，支持 90 天保留 | 中 |

### 2.6 自然语言交互

| 编号 | 功能 | 描述 | 优先级 |
|------|------|------|--------|
| F6-1 | Web 对话界面 | B/S 架构的聊天式交互 | 高 |
| F6-2 | 流式响应 | 支持 SSE 流式输出 | 低 |
| F6-3 | 会话管理 | 支持多会话隔离和历史记录 | 中 |
| F6-4 | 快捷指令 | 提供常用运维指令快捷入口 | 中 |

## 3. 非功能需求

### 3.1 确定性与可靠性
- 严禁 Agent 在未授权情况下修改系统关键配置文件
- 所有修改类操作必须经过安全校验和人工确认

### 3.2 抗注入能力
- Agent 需能识别提示词注入（Prompt Injection）
- 防止攻击者通过对话诱导 Agent 执行恶意代码

### 3.3 兼容性
- 支持 LoongArch 架构 + 麒麟高级服务器版 V11
- 优先使用国产软件栈

### 3.4 性能
- 单次请求响应时间 < 30 秒（含 LLM 推理）
- 支持并发会话数 ≥ 10

## 4. 部署环境

- **架构**: LoongArch
- **操作系统**: 麒麟高级服务器版 V11
- **开发语言**: Python 3.9+
- **Web 框架**: FastAPI
- **大模型**: DeepSeek / Qwen3 等国产开源模型（兼容 OpenAI API 格式）
